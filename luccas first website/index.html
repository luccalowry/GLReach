Luccas First Website

Learn web basics while practicing Codex and GitHub.

This mini project is intentionally simple: one HTML file, one CSS file, and one JavaScript file. That makes it easy to understand what changes Codex makes and easy to track them in GitHub.

How this project is set up

You are looking at a static website. That means you can open index.html directly in a browser and it will work without installing anything.

  • HTML gives the page structure.
  • CSS controls the look and layout.
  • JavaScript adds interaction.

Workflow

A beginner-friendly Codex + GitHub loop

1

Ask Codex for a small change

Example: “Add a new section about my hobbies” or “Make the hero background warmer and more playful.”

2

Review what changed

Open the edited files and compare before committing. The goal is to learn from the changes, not just accept them blindly.

3

Commit to GitHub in small chunks

Make one commit per idea. That keeps your history readable and makes mistakes easy to undo.

GitHub habits

What efficient development looks like

  • Commit often, but keep each commit focused.
  • Use clear commit messages like Add hero section copy.
  • Push your work regularly so GitHub becomes your backup.
  • Read diffs before you merge or share anything.

Simple first goal

Customize this page until it feels like yours. Change the title, colors, sections, and writing. Once you do that a few times, the Codex workflow starts to feel natural.
