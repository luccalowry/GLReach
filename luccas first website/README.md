# Luccas First Website

This folder is a beginner-friendly website project designed to help you learn:

- how a simple website is structured
- how to ask Codex for useful, small changes
- how to use Git and GitHub without getting overwhelmed

## Files

- `index.html`: page structure and content
- `styles.css`: colors, layout, spacing, and visual style
- `script.js`: small interactive behaviors

## How to use this project

1. Open `index.html` in your browser.
2. Read the page and pick one tiny thing you want to change.
3. Ask Codex to make that one change.
4. Review the updated files.
5. Commit the change to Git.
6. Push to GitHub.

## Good starter requests for Codex

- "Explain this HTML file to me section by section."
- "Add an About Me section under the hero."
- "Change the color palette to ocean colors."
- "Make the buttons feel more playful."
- "Teach me what this JavaScript file does line by line."

## Good Git habits

- Keep each commit focused on one idea.
- Write commit messages that describe the change clearly.
- Push your work often.
- If Codex changes something you do not understand, ask for an explanation before committing.

## Suggested Git commands

```bash
git status
git add .
git commit -m "Create first website project"
git push -u origin main
```

## A strong learning loop

Use Codex for speed, but stay curious:

- Ask for small edits.
- Read the diffs.
- Test in the browser.
- Ask follow-up questions.
- Commit once the change makes sense to you.
